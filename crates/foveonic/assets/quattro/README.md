# Quattro calibration maps

These 24 blue spatial-gain maps originate from the reference implementation distributed by SIGMA Corporation, version 6.9.0.0. They were copied unchanged from its `Contents/Resources/BData` directory. Original filenames are preserved.

Each file contains 184×116 little-endian Float32 values followed by a four-byte height/width trailer. Camera identifiers 80–83 each have six aperture/focus maps. The processor embeds these data in the executable, so rendering does not require a separate installation or resource directory.

The SHA256 values below identify the imported bytes. This attribution applies to these calibration data separately from the project's authored processing code.
