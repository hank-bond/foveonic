# Color-field highlight reconstruction

## Requirements

- Offer three highlight choices: **Classic**, **Color Field: Local**, and **Color Field: Global**. Classic remains the default and retains existing threshold behavior and output. All choices use the independent highlight enable control.
- Local and Global must share reliability, anchors, native equations, color reconstruction, donor selectivity, and application. Local replaces the global brightness solve with 64 damped local sweeps. Global retains the global brightness solve. Method selection must not create separate major color-recovery implementations.
- Implement the pinned reference implementation's tone anchors, native-resolution gradient equations, 8-pixel color grid, calibrated color metric, region-conditioned boundaries, donor-distance weighting, color equations, and evidence-limited native application in WGSL. Build the faithful mode on the full sensor raster before the active-area crop, preserving the reference grid origin and boundary neighbors. Float32 arithmetic may differ from the CPU reference. GPU compaction must assign native and color unknowns in ascending physical order so solver reductions repeat for identical inputs and settings. Preserve exact cached/fresh recovery and downstream outputs on the same device. Production must not expose exploratory solver, grid, work-area or evidence-weighting variants.
- Source clipping reliability must derive from immutable original samples and black/white calibration before corrections. Repaired samples must not become independent color evidence. Healthy samples and retained inputs must remain unchanged.
- Keep evidence gathering, solving, and application owned by the color-field operation. Declare original samples and black levels as graph dependencies rather than hiding unrelated work in stock calibration or repair. Camera metadata preparation remains host-side. Photographic image arithmetic remains on the GPU.
- Both TIFF and DNG technical processing must select the method consistently. Tone, exposure, and output packaging remain downstream. Preserve signed samples and recovered headroom.
- Preserve the reference algorithm's default photographic constants at strength 0. Local and Global share a selection strength from 0 to 1, defaulting to 0. Higher values reject more inconsistent evidence. Map positive strength to a log-ratio standard-deviation cutoff of `0.005 / strength`, approaching an unfiltered solve at zero. At strength 1 the cutoff is 0.005. Observations below the effective cutoff retain their weight, observations between the cutoff and twice the cutoff taper smoothly, and observations at or above twice the cutoff are rejected from affected grid color equations. The original per-cell neutral coefficient and graph guides remain unchanged. Do not add a uniform neutral bias.
- Put the Method dropdown first, then one Highlights slider and independent enable checkbox for all three methods. Classic alone retains A, its camera-relative threshold and automatic behavior. Local and Global have no A button: strength 0 means the original reconstruction without extra consistency filtering. Selection starts and resets at 0. The checkbox alone disables highlight reconstruction. The useful manual tradeoff may differ between photographs.
- Store scalar selectivity strength in editing sidecars and effective processing parameters in cache keys. Use the strength consistently in GUI, CLI, TIFF and DNG processing. Preserve Classic threshold and color-field strength independently across method switches and enable changes. Classic ignores color-field tuning. Migrate saved raw cutoffs to equivalent strengths and retired automatic or neutral-restraint prototype settings to 0. Explicit strength settings, including a migrated null or 0, take precedence over retired fields. Do not retain a retired processing path.
- The single Highlights row replaces agreement/boundary and neutral-restraint editing. Production stores only brightness selection and selectivity. Agreement, boundary agreement, donation strength, grid spacing, work area, iteration counts and tolerances are fixed algorithm choices, not GUI or CLI controls. Preserve Classic threshold and color-field selectivity across method switches. Classic threshold has no effect on either color-field choice. Retired experimental settings migrate to the supported full-sensor method without retaining an alternate recovery path.
- Validate reliability quantization separately from the equations. Identical-evidence CPU-reference tests must use the same quantized masks; float32 normalization may differ by one u8 bin at rounding boundaries. Validate float32 accuracy with identical-input CPU-reference tests, numerical residual checks, photographic comparisons and completed-render profiling. Solver failures must be reported rather than silently selecting another method.
